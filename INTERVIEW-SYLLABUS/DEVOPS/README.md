# Cloud / DevOps interview syllabus

Questions have permanent IDs. Each question keeps video options and code discussions separated by source video.

- **[IC-1](IC-1.md)** — What Git branching and release promotion workflow have you used?
- **[IC-2](IC-2.md)** — How do feature branches progress through QA, staging and production?
- **[IC-3](IC-3.md)** — What happens after a pull request is merged and what tools trigger the pipeline?
- **[IC-4](IC-4.md)** — Explain CI versus continuous delivery and deployment, including automated gates.
- **[IC-5](IC-5.md)** — What is a Dockerfile, and how are Docker images used to run a Java application?
- **[IC-6](IC-6.md)** — How would you run and scale ten microservices with Kubernetes?
- **[IC-7](IC-7.md)** — How would you troubleshoot a repeatedly crashing Kubernetes pod in production?
- **[IC-8](IC-8.md)** — How would you roll back a broken deployment to a previous container image?
- **[IC-9](IC-9.md)** — What is infrastructure as code, and how would you use Pulumi for cloud alerts?
- **[IC-10](IC-10.md)** — Compare Maven and Gradle as Java build tools.
- **[IC-11](IC-11.md)** — What is the purpose of pom.xml and how does Maven resolve dependencies?
- **[IC-12](IC-12.md)** — Compare Kanban and Scrum and explain how they affect a team's delivery workflow.
